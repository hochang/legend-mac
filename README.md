基于游泳的鱼的金庸群侠传lua复刻版，修改gbk编码为utf8编码，移植到 macOS 上。

在 Lua 5.4 下编译成功，使用 SDL 2。

### 编译

 - 用 Homebrew 安装依赖

```
brew install lua sdl2 sdl2_image sdl2_mixer sdl2_ttf
```

 - 编译

```
cd src
make
```

### 运行

```
cd bin
./jy
```

### ubuntu 下编译

```
sudo apt-get install libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev lua5.4 liblua5.4-dev build-essential pkg-config gcc
cd src
make
cd ../bin
./jy # run game
```

## 本版本的修改

### 显示和操作

 - **画面放大**：游戏仍按 640×480 绘制，显示时按 `CONFIG.WindowScale`（默认 2）放大到窗口，保持宽高比，多余部分填黑；全屏使用桌面分辨率。
 - **贴图透明修正**：macOS 窗口表面带 alpha 通道时，贴图的透明色（背景）会显示出来。现在透明色像素的 alpha 置 0，背景正确去除。
 - **走路更快**：按住方向键可连续走路，不依赖系统键盘重复速度（`CC.WalkFrame` 每步毫秒数，`CC.WalkHoldDelay` 开始连续走路的延时，见 `jyconst.lua`）。
 - **Y/N 询问**：按 Y 选“是”，其他字母或数字键选“否”。

### 新游戏

 - 开始新游戏时可选择“使用最高初始属性”：各项能力 30、内力 40、阴阳调和、生命增长 10（同原版 `baberuth` 秘技），资质可自行输入 0-100。

### 难度：`CONFIG.DIFFICULTY`

在 `bin/config.lua` 中设置。原版的数值和公式是通过反汇编原版 DOS 程序 (`Z.DAT`) 核对的；人物、物品、武功、场景、商店和战斗数据与原版完全一致。

 - `1`（默认）：使用原版 DOS 的战斗公式和敌人 AI
 - `2`：使用 lua 移植版原有的公式和加强的敌人 AI

| 项目 | 1 原版 | 2 移植版 |
|---|---|---|
| 敌人/自动战斗 AI | 随机选择武功；按品德、资质选择目标；按原版条件医疗、解毒、用毒、发暗器、吃药、逃跑 | 选最强武功，尽量同时打多人 |
| 每次攻击消耗内力 | floor(等级/2)×消耗内力，按实际使用的等级计算（1 级武功不耗内力） | floor((等级+1)/2)×消耗内力 |
| 防御高于攻击时的伤害 | 攻击力/10 ± 随机4 | 1–10 |
| 武功带毒 | (中毒点数−目标抗毒)/15，按实际武功等级，最高 99 | 中毒点数/15，不减抗毒 |
| 医疗 | 受伤程度减少医疗能力的全部值；平时医疗消耗 2 点体力 | 受伤程度只减少实际治疗量 |
| 武学常识加成 | 武学常识×2，只计算活着的人 | 武学常识×1 |
| 暗器 | 目标受伤程度 >66 时造成全部伤害；毒暗器直接加全部中毒点数 | 伤害减半，中毒点数大幅减少 |

以下几项不论难度，一律改为原版做法：

 - 战斗中解毒需要体力 >50（移植版为 ≥10）
 - 距离对伤害的影响：距离 ≤10 时按距离递减（移植版为 <10）
 - 升级时技能成长：技能 >20 才增长（移植版 ≥20），暗器技巧每次升级都增长
 - 物品 0、2 恢复为原版的康倍特（体力 +20）和白岚氏鸡精（生命 +20）。移植版原来改成了醉生梦死酒（忘记武功）和还魂液（战斗中复活）。新游戏数据和存档 r1–r3 都已修改。
 - 移植版新增的河洛客栈韦大宝（典当、地下市场、佣兵行会、瞬息千里）保留不变。

### 语言：`CONFIG.Language`

在 `bin/config.lua` 中设置，修改后重新启动游戏即可。

 - `"zh_CN"`（默认）：简体中文
 - `"zh_TW"`：繁体中文

| 文字 | 简体 (zh_CN) | 繁体 (zh_TW) |
|---|---|---|
| 界面文字（菜单、提示、战斗信息、程序中的对话） | `script/lang/zh_CN.lua` | `script/lang/zh_TW.lua` |
| 人物、物品、武功、场景名称和说明 | `data/ranger_zh_CN.grp` | `data/ranger.grp` |
| 剧情对话 | `script/oldtalk_zh_CN.grp` | `script/oldtalk.grp` |

 - 程序代码中不再有显示用的文字，全部放在语言文件中，代码里用 `LANG.xxx` 引用；人物属性的显示名称在 `LANG.Attr`，通过 `AttrName()` 取得。
 - 简体文件由繁体（或原简繁混杂的）文字用 OpenCC 转换而来，繁体语言文件使用台湾用字（為、裡、著）。
 - 读取旧存档时，人物、物品、武功、场景名称会自动换成当前语言；主角姓名保持存档中的名字（默认的“徐小侠/徐小俠”会随语言切换）。
 - 已知问题：繁体模式下剧情对话 `oldtalk.grp` 仍主要是简体。
 - 修改对话后删除对应的 `oldtalk*.idx`，游戏启动时会自动重新生成。
